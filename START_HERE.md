## 🔧 Example Problems to Try

### Fibonacci Sequence
```
Recurrence: a(n) = a(n-1) + a(n-2)
Initial: a(0) = 0, a(1) = 1
```

### Geometric Growth
```
Recurrence: a(n) = 2*a(n-1)
Initial: a(0) = 3
```

### Tower of Hanoi
```
Recurrence: a(n) = 2*a(n-1) + 1
Initial: a(1) = 1
```

### Compound Interest
```
Recurrence: a(n) = 1.07*a(n-1)
Initial: a(0) = 10000
```

## 🆘 Need Help?

### Quick Fixes

**Can't login?**
- Make sure you registered first
- ID and username are case-sensitive
- Try registering again if forgotten

**Theme not changing?**
- Click "💾 Save Settings" after changing
- Restart the app if needed

**Solver not working?**
- Check recurrence format: `a(n) = 2*a(n-1)`
- Add at least one initial condition
- Try an example problem first

**Missing dependencies?**
- Run: `pip install -r requirements.txt`
- Check that Python 3.10+ is installed
